## 💾 백업 시스템

### ✅ **이중 백업**
1. **Supabase (메인)**: 클라우드 저장
2. **localStorage (백업)**: 로컬 저장

### ✅ **자동 동기화**
- 데이터 추가/수정/삭제 시 Supabase와 localStorage에 동시 저장
- 서버 오류 시 자동으로 localStorage fallback

---

## 🔄 데이터 관리

### **새 자료 추가:**
```
콘텐츠 관리 → 시험지 작성 → 저장
    ↓
자동으로 Supabase + localStorage 저장
```

### **자료 수정:**
```
업로드된 자료 → 수정 버튼 → 내용 수정 → 저장
    ↓
자동으로 Supabase + localStorage 업데이트
```

### **자료 삭제:**
```
업로드된 자료 → 삭제 버튼
    ↓
Supabase + localStorage에서 삭제
```

## 🆘 문제 해결

### **샘플이 안 보여요**
1. **새로고침** (F5)
2. 브라우저 콘솔(F12) 확인
3. 네트워크 오류 확인

### **서버 저장 실패**
- localStorage에 자동 저장됨 (안전!)
- 네트워크 확인 후 다시 시도

### **데이터 초기화**
```javascript
// 브라우저 콘솔(F12)에서 실행
localStorage.removeItem('uploads');
location.reload();
```
