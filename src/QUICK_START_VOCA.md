## ✅ Supabase 연결 완료!

서버 연결이 성공적으로 완료되었습니다. 이제 7,500개 단어를 생성하고 학습을 시작할 수 있습니다!

---

## 📝 5분 안에 시작하기

### **STEP 1: LMS 관리 페이지 접속**
1. 왼쪽 사이드바에서 **"LMS 관리"** 클릭
2. 상단 탭에서 **"Voca 관리"** 선택

### **STEP 2: 7,500개 샘플 단어 생성**
1. 오른쪽 상단 **"샘플 생성 (7,500개)"** 버튼 클릭
2. 확인 팝업에서 **"확인"** 클릭
3. 3-5초 대기 (Supabase에 업로드 중)
4. ✅ "7500개의 샘플 단어가 Supabase에 저장되었습니다!" 메시지 확인

**생성되는 내용:**
```
📘 TOEFL  : 30일 × 50단어 = 1,500개
📗 SAT    : 30일 × 50단어 = 1,500개 (영영풀이 포함)
📙 IELTS  : 30일 × 50단어 = 1,500개
📕 TOEIC  : 30일 × 50단어 = 1,500개
📔 ACT    : 30일 × 50단어 = 1,500개
────────────────────────────────────
총합      : 150일 × 50단어 = 7,500개
```

### **STEP 3: 시험 생성하기**
1. 왼쪽 사이드바 **"인증시험"** → 원하는 시험 선택 (예: TOEFL)
2. 하단 **"Voca"** 버튼 클릭
3. 시험 선택 및 Day 선택
   - 예: **TOEFL** 선택
   - **Day 1, Day 2, Day 3** 체크
4. 문제 유형 및 개수 설정:
   ```
   영어 → 한글 (표제어): 10문제
   영어 → 한글 (동의어): 5문제
   한글 → 영어 (표제어): 5문제
   ```
5. **"시험 출제"** 버튼 클릭
6. 🎯 시험 시작!

## 🆘 문제 해결

### "단어가 안 보여요!"
→ **새로고침** (F5) 후 "📊 통계 보기" 확인

### "서버 저장 실패"
→ localStorage에는 자동 저장됨 (안전!)
→ 나중에 "localStorage → Supabase" 버튼으로 동기화

### "샘플 단어 다시 생성하고 싶어요"
→ "샘플 삭제" → "샘플 생성 (7,500개)"
