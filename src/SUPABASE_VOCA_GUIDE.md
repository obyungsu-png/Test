# 📚 N Study Hub - Supabase 어휘 관리 시스템

## 🎉 연결 완료!

Supabase와 성공적으로 연결되었습니다. 이제 7,500개의 어휘 단어를 서버에 안전하게 저장하고 관리할 수 있습니다.

---

## 🚀 빠른 시작

### 1️⃣ **샘플 단어 생성 (7,500개)**

**LMS 관리** → **Voca 관리** 페이지에서:
- **"샘플 생성 (7,500개)"** 버튼 클릭
- 5개 시험 × 30일 × 50단어 = **7,500개 자동 생성**
- Supabase 서버에 즉시 저장됨

**포함 시험:**
- 📘 TOEFL (학술적 영어)
- 📗 SAT (고급 어휘)
- 📙 IELTS (일상+학술 영어)
- 📕 TOEIC (비즈니스 영어)
- 📔 ACT (대학 진학 기본)

---

### 2️⃣ **기존 localStorage 데이터 마이그레이션**

이미 localStorage에 단어가 있다면:
- **"localStorage → Supabase"** 버튼 클릭
- 기존 데이터를 서버로 자동 이전

---

## 📊 데이터 구조

### Supabase KV Store 키:
```
nstudy_voca_words      → 모든 단어 데이터
nstudy_voca_day_names  → Day 이름 매핑
```

### 단어 데이터 구조:
```typescript
{
  id: string;
  exam: 'TOEFL' | 'SAT' | 'IELTS' | 'ACT' | 'TOEIC';
  day: number;              // 1-30+
  english: string;          // 영어 단어
  korean: string;           // 한글 뜻
  definition?: string;      // 영영풀이 (SAT 전용)
  synonyms: string;         // 유의어 (쉼표 구분)
}
```

## 🔧 주요 기능

### ✅ 단어 관리
- ➕ 단어 추가/수정/삭제
- 📤 CSV 일괄 업로드
- 📥 CSV 내보내기
- 🔍 단어 검색

### ✅ 시험 생성
- 📝 영→한, 한→영, 영영→영 문제 출제
- 🎯 Day별, 단어별 선택 가능
- 📊 자동 채점 및 오답 분석

### ✅ Day 관리
- 🏷️ Day 이름 변경 (예: "핵심 어휘", "고난도 단어")
- ➕ Day 31 이상 사용자 정의 학습 세트 추가
- 📂 시험별 최대 30일 기본 제공

## 🌐 API 엔드포인트

### 단어 관리:
```
GET    /voca/words          → 모든 단어 조회
POST   /voca/words          → 단어 저장 (전체 교체)
POST   /voca/words/bulk-add → 단어 일괄 추가
DELETE /voca/words/:id      → 단어 삭제
PUT    /voca/words/:id      → 단어 수정
```

### Day 이름:
```
GET    /voca/day-names      → Day 이름 조회
POST   /voca/day-names      → Day 이름 저장
```
